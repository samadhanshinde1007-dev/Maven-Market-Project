# Maven Market Sales & Performance Analytics Dashboard

## Short Description

An interactive, end-to-end Power BI analytics dashboard built for **Maven Market**, a multi-national supermarket chain operating across North America (USA, Mexico, and Canada). This project transforms multi-table transactional, product, customer, and regional store data into actionable insights—tracking revenue performance against targets, evaluating product profit margins, measuring return metrics, and highlighting regional sales distributions.

## Tech Stack

* **Business Intelligence & Visualization:** Microsoft Power BI Desktop
* **Data Transformation & Modeling:** Power Query (ETL pipeline), DAX (Data Analysis Expressions) for complex KPIs and time-intelligence calculations
* **Data Storage / Input:** CSV / Relational Flat Files

## Data Source

* Data provided by **Cravita Technologies Pvt Ltd**

## Key Features & Highlights

### 1. High-Impact KPI Performance Summary

* Calculated dynamic metrics including **Total Revenue ($1.76M)**, **Total Profit ($1.05M)**, overall **Profit Margin (59.67%)**, and **Total Transactions (270K)**.
* Advanced time-intelligence measures tracking **YTD Revenue ($1.20M)**, **60-Day Revenue**, **Last Month Revenue ($1.64M)**, and target compliance.

### 2. Target vs. Actual Performance Tracking

* **Monthly Goal Benchmarks:** Real-time visual status monitoring for Current Month Transactions, Profit, and Returns against predefined company targets.
* **Gauge Visualizations:** Visual progress tracking against revenue goals (e.g., $119.48K current vs. $120.16K target).

### 3. Granular Brand & Product Analysis

* Itemized table metrics dissecting performance across **111 product brands** and over **1.56K unique products**.
* Conditional color-coded formatting highlighting top-performing brands (e.g., *Hermanos*, *Ebony*, *Tell Tale*) by total revenue, profit margin, and product return rates.

### 4. Interactive Regional & Spatial Analytics

* Integrated map visualization highlighting regional transaction distributions across **USA, Mexico, and Canada**.
* Region-specific slicers for quick geographical breakdown and drill-down analysis.

### 5. Sales & Returns Operational Monitoring

* Detailed breakdown tracking return volumes (**8K items / 0.99% Return Rate**) and transaction distributions across weekdays vs. weekends (**28.4% weekend transactions**).
* **Weekly Revenue Trending:** Bar chart visualizations tracking revenue trajectory over extended monthly and yearly timelines (1997–1998).
